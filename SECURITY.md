## CD Exam Control security

The collector uses authenticated Moodle AJAX functions and validates ownership and course-module context. Reports and exports require capabilities and permitted groups. Never include real student data, session keys or credentials in a public issue. Review data minimisation, retention, privacy API coverage and CSV escaping whenever new fields are introduced. Report suspected vulnerabilities privately to the maintainer through an agreed channel; a browser signal is not a secure anti-tampering boundary.
