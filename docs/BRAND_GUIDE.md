# CD ExamFocus brand guide / Guía de marca

## Public name

**CD ExamFocus** is the public product name. The technical Moodle component remains `quizaccess_cdexamsave`, and the installation directory remains `cdexamsave`. Keeping those identifiers avoids breaking existing installations, upgrades, database tables, capabilities and repository links.

Use **CD ExamFocus (formerly CDexamSave)** only during the transition. After the first widely distributed release, use **CD ExamFocus** alone except where the technical component must be identified.

## Positioning

**English tagline:** Privacy-first focus monitoring for Moodle quizzes.

**Spanish tagline:** Supervisión del foco para cuestionarios Moodle, respetuosa con la privacidad.

**One-line promise:** Know when the active exam window loses focus, without cameras, screen recording or external services.

**AI-resources message:** Detects and documents when a student leaves the active exam window, a key indicator of access to AI or other unauthorised external resources.

The strongest valid result statement is **No focus-loss incidents were detected during this attempt**. Never convert that statement into **AI was not used** or **AI-free attempt guaranteed**. The plugin cannot observe a second device, an integrated browser assistant, an operating-system overlay, previously prepared content or a disabled client-side monitor.

Do not describe the plugin as a locked browser, anti-cheating proof, automatic proctoring system or tamper-proof client. It detects browser focus signals and supports human review.

## Visual system

- Institutional burgundy `#960000`: primary identity and the active exam window.
- Graphite `#2F3944`: professional neutral for typography and the `D` monogram.
- Muted teal `#39777A`: complementary functional accent for the focus signal.
- Warm grey `#EEE9E9`: quiet borders and secondary surfaces.
- White `#FFFFFF`: the default background.

The approved icon places a multiple-choice answer sheet inside an abstract aperture made from burgundy and muted-teal folded planes. The selected answer communicates assessment and focus; the small embossed `CD` signature keeps the authorship discreet. The white field and restrained palette give the mark an institutional, professional character without suggesting invasive surveillance or browser lockdown.

## Voice

Lead with the practical benefit, then explain privacy and limitations. Use precise, calm language. Prefer **focus-loss incident** to **cheating event** and **human review** to **automatic detection of misconduct**.
